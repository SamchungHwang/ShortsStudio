# 제품 자산

제품마다 폴더 하나를 둔다. 폴더 이름은 `product_bible.yaml` 의 제품 id 와 같다.

```
assets/products/<제품 id>/
  photos/                    본인이 찍은 제품 사진을 넣는다 (jpg, png, webp). 이름 순으로 앞의 6장을 쓴다
  reference/                 사람이 고른 레퍼런스 이미지. `ass sheet --select` 가 채운다. 손으로 고치지 않는다
  reference_manifest.json    무엇을, 누가, 언제, 어느 후보에서 골랐는지의 기록
```

- 사진은 본인이 찍었거나 쓸 권리가 있는 것만 넣는다. 다른 곳에서 내려받은 제품 사진은 넣지 않는다.
- 모아랩과 하루온은 가상의 브랜드라 사진이 없다. 예제는 외형 서술만으로 레퍼런스를 만든다.
- 후보 이미지는 `outputs/sheets/<제품 id>/v001/` 처럼 버전별로 쌓인다. 고르기 전에는 여기에 오지 않는다.
