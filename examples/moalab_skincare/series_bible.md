# 모아랩 스킨케어 series_bible (초안 v0.1)

러닝 예제는 가상의 스킨케어 브랜드 **모아랩(MOALAB)** 이다. 실제 브랜드가 아니다.
이름은 작업용이며, 실제 상표와 겹치지 않는지 확인한 뒤 확정한다.
비교 편에 나오는 타사 **하루온(HARUON)** 도 가상의 브랜드다.

## 한 브랜드, 세 형식

| 형식 | 예제 | 장면 뼈대 (15초 × 3) | 폴더 |
|---|---|---|---|
| 제품 설명 | 수분 세럼 소개 | problem → solution → usage | `episodes/product_intro/` (초안 있음) |
| 제품 비교 | 모아랩 젤 선크림과 하루온 크림 선크림 | criteria → side_by_side → verdict | `episodes/comparison/` (7장에서 작성) |
| 정보 전달 | 스킨케어 바르는 순서 | question → methods → wrap_up | `episodes/info/` (6장에서 작성) |

## 화면 규칙
- 진행자 얼굴이 없는 구성이 기본이다: 제품, 손, 질감 클로즈업.
- 정보는 내레이션과 자막이 전달하고, 화면은 근거를 보여 준다.
- 자막은 공백 제외 12자 이내. 영상에 글자를 생성시키지 않고 조립 단계에서 얹는다.

## 사실과 표현
- 내레이션과 자막이 말하는 제품 사실은 `product_bible.yaml` 의 facts 에서만 가져오고, 구간마다 evidence 로 연결한다.
- `configs/claims_lexicon.yaml` 의 표현을 쓰지 않는다. 사전은 1차 거름망이고 초기 가정값이다.
- 타사 제품이 나오는 장면은 컴파일 결과에 `needs_human_approval: true` 가 붙는다. 사람이 승인한 뒤 생성한다.
- 타사 제품은 깎아내리지 않는다. 같은 기준으로 나란히 보여 주고 “누구에게 맞는가”로 맺는다.

## 내 제품으로 바꾸기
1. `product_bible.yaml` 에 내 제품의 외형(appearance_en)과 사실(facts, 출처 포함)을 적는다.
2. 제품 사진을 `assets/products/<제품 id>/` 에 넣는다(5장).
3. `source_briefs/` 의 예시를 복사해 내 소재(아이디어, 본인 블로그 글, 본인 영상의 대본)로 바꾼다.
4. 장면 사양의 products, 내레이션, evidence 를 고친 뒤 `python scripts/compile_scenes.py` 로 확인한다.

## 확인이 필요한 것
- 장면별 내레이션과 구간 배분은 3.4절 집필 때 확정한다. 지금 사양은 컴파일러와 첫 호출을 돌려 보기 위한 초안이다.
- 제품 라벨이 영상에서 유지되는지는 실험 E12, 한국어 내레이션 경로는 E13에서 확인한다.
